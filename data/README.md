# Dataset

This project uses the PlantVillage dataset for plant disease classification.

The dataset contains images of healthy and diseased plant leaves from different crops.

## Dataset Source

PlantVillage Dataset:
https://www.kaggle.com/datasets/emmarex/plantdisease


## Dataset Organization

The dataset should be organized as:


data/

├── train/
│ ├── class_1/
│ ├── class_2/
│ └── ...
│
├── val/
│ ├── class_1/
│ ├── class_2/
│ └── ...
│
└── test/
├── class_1/
├── class_2/
└── ...



## Classes

The project contains 15 plant disease classes including:

- Pepper diseases
- Potato diseases
- Tomato diseases


## Note

The dataset is not included in this repository due to its size.

Please download the dataset separately and place it in this directory.
